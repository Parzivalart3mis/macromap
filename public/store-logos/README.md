# Store logos

Drop a logo image here named exactly `<store-slug>.png` and it will appear on
the Food page's chain-store tiles (and anywhere `StoreLogo` is used). Any store
without a matching file keeps the branded initial letter — so this folder can
stay empty and nothing breaks.

- **Filename:** `<slug>.png` (lowercase, matches the store's slug).
- **Best results:** a square-ish, transparent-background PNG. It's shown in a
  36px rounded white tile with `object-contain` padding.
